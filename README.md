# Traduction française pour nophenia.
Utilisez [godot-override-mod-loader](https://github.com/totobono4/godot-override-mod-loader).

Mettez le zip dans le dossier `override-mods`.
[dream_translator_api](https://github.com/totobono4/nophenia-dream_translator_api) est requis pour fonctionner.

# Installation
Téléchargez [la dernière version]([https://github.com/totobono4/nophenia-dream_translator_api/releases/tag/0.0.2](https://github.com/totobono4/nophenia-french_dream/releases/tag/0.0.3)) et mettez le mod dans le dossier `override-mods`.
